# 角色头顶信息展示功能

## 概述

玩家可通过 `@overhead` 命令开关头顶信息展示，开启后在角色头顶以聊天气泡形式周期性显示当前倍率信息和网络延迟，仅玩家自己可见。

## 使用方式

在游戏聊天框中输入：

```
@overhead
```

每次输入切换开/关状态。开启后每5秒刷新一次头顶气泡。

## 展示效果

角色头顶出现聊天气泡，内容如下：

```
⚡ 角色实时信息
经验: 3.0x | 掉落: 2.0x
BOSS爆率: 3.0x | 金币: 1.5x
延迟: 45ms
```

## 展示内容说明

| 项目 | 说明 | 计算方式 |
|------|------|----------|
| 经验 | 经验倍率 | 基础经验倍率 × Buff加成(神圣祈祷等) × 家族加成 |
| 掉落 | 普通掉落倍率 | 基础掉落倍率 × 家族掉落加成 |
| BOSS爆率 | BOSS掉落倍率 | 基础掉落/大区掉落 × 大区BOSS掉落 |
| 金币 | 金币倍率 | 基础金币倍率 |
| 延迟 | 网络延迟 | 当前时间 - 最后一次收到PONG响应时间(ms) |

## 技术架构

### 封包机制

使用 MapleStory 客户端的 **CHATTEXT（0xA2）** 封包，通过 `PacketCreator.getChatText()` 构建：

```java
PacketCreator.getChatText(characterId, text, isGM, showLevel)
```

- `characterId`: 角色ID（让气泡显示在角色头顶）
- `isGM`: `false`（普通玩家样式）
- `showLevel`: `0`（普通显示）

### 发送方式

封包**仅发送给玩家自己**（`client.sendPacket()`），**不广播到地图**，其他玩家看不到。

### 定时任务

- 使用 `TimerManager.getInstance().register(runnable, repeatTime, delay)` 注册定时任务
- 刷新间隔：**5000ms（5秒）**
- 首次延迟：**5000ms（5秒）**

### 生命周期

- 开启：输入 `@overhead` → `Character.startOverheadInfo()`
- 关闭：再次输入 `@overhead` → `Character.stopOverheadInfo()`
- 下线自动清理：`Character.empty()` 中取消定时任务

## 关键代码

### Character.java - 核心方法

```java
/**
 * 切换头顶信息展示开关
 */
public void toggleOverheadInfo() {
    if (overheadInfoEnabled) {
        stopOverheadInfo();
    } else {
        startOverheadInfo();
    }
}

/**
 * 开启头顶信息展示 - 每5秒向玩家自身发送CHATTEXT封包
 */
private void startOverheadInfo() {
    overheadInfoEnabled = true;
    overheadInfoTask = TimerManager.getInstance().register(() -> {
        if (!overheadInfoEnabled || !isLoggedIn() || client == null) {
            stopOverheadInfo();
            return;
        }
        sendOverheadInfo();
    }, 5000, 5000);
}

/**
 * 构建并发送头顶信息气泡
 */
private void sendOverheadInfo() {
    long latency = client.getLastPong() > 0 
        ? System.currentTimeMillis() - client.getLastPong() : 0;

    float expBuff = 1;
    Integer expBuffValue = getBuffedValue(BuffStat.EXP_BUFF);
    if (expBuffValue != null) {
        expBuff = 2;
    }

    StringBuilder sb = new StringBuilder();
    sb.append("#e⚡ 角色实时信息#n\r\n");
    sb.append("经验: #e#b").append(String.format("%.1f", 
        getExpRate() * expBuff * getFamilyExp())).append("x#k#n");
    sb.append(" | 掉落: #e#b").append(String.format("%.1f", 
        getDropRate() * getFamilyDrop())).append("x#k#n\r\n");
    sb.append("BOSS爆率: #e#b").append(String.format("%.1f", 
        getBossDropRate())).append("x#k#n");
    sb.append(" | 金币: #e#b").append(String.format("%.1f", 
        getMesoRate())).append("x#k#n\r\n");
    sb.append("延迟: #e#b").append(latency).append("ms#k#n");

    client.sendPacket(PacketCreator.getChatText(getId(), sb.toString(), false, 0));
}
```

### Client.java - 延迟支持

```java
/**
 * 获取最后一次收到PONG响应的时间戳，用于计算网络延迟
 */
public long getLastPong() {
    return lastPong;
}
```

## 扩展可能

- 可增加更多展示项（如任务倍率、旅行倍率、家族Buff状态等）
- 可增加配置项控制默认开关状态
- 可通过 `GameConfig` 添加全局开关（如 `use_overhead_info`）
- 可通过 `ExtendValue` 持久化玩家的开关偏好到数据库
- 可改造为定时向全地图广播（让其他玩家也能看到头顶信息）
