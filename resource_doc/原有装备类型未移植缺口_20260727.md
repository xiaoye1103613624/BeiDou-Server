## 建议优先动作（仅研究建议）

1. **批量：Live→Srv Character XML**（Weapon / Accessory / Ring / Longcoat / Shoes / PetEquip），策略 OVERWRITE 勿覆盖已有；Cap 先处理双向差再动 `01009*`。  
2. **同批补 String.Eqp**（无名≈与 Live-only 重合）。  
3. **0118/0116**：先定是否做槽；不做则不必优先拷剩余 0118 XML。  
4. **0115**：补齐 Srv 缺的 24 件即可与 Live 对齐。  
5. 若要挖「比 Live 还新」的系列：需另备更高版本 Character 源（当前 V16/079/AdventureMS 不够）。
