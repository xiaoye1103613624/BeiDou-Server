# 第二吊坠：悬停有信息但无图标 — 2026-07-26g

## 现象
鞋子右侧悬停可出第二坠装备信息，不悬停看不到图标。

## 根因
| 环节 | 说明 |
|------|------|
| HitTest | ijl15 外挂命中 BP51 → **tooltip 正常** |
| 图标绘制 | 循环上界 = `50 + (flag?1:0)`（`setnz`+`add 0x32` @ `0x007FEFB9`） |
| 旗标来源 | 装备窗初始化从 **`CWvsContext+0x387C`** 拷到 `CUIEquip+0x5E8`（`mov eax,[BE7918]; mov eax,[eax+0x387C]`） |
| 缺口 | 服务端从未发送 **`SET_EXTRA_PENDANT_SLOT(0x79)`** → context 恒为 0 → 绘制扫不到 index 50 |

## 修复
1. **服务端** `PlayerLoggedinHandler`：`getCharInfo` 后发送 `PacketCreator.setExtraPendantSlot(true)`
2. **ijl15**：`PumpExtraPendantFlags` 同时写 `CWvsContext+0x387C` 与 UI `+0x5E8`（`pendant2_ui=true` 时）
3. 仍 **禁止** ForceDrawLoop；坐标仍为鞋子右侧 `(104,200)`

## 验证
1. **重启服务端**（加载 Java 改动）
2. 关客户端再开 Client_1（新 dll）
3. 登录进图 → 装备栏鞋子右侧应能看到第二坠图标；悬停仍正常
4. 若卡登录：`pendant2_ui=false`
