也是无聊，就baidu随便找了个私服，玩了079版本的。
也是老G人好，就无偿分享了我服务器资源和修改工具。
开始是觉得，有些特效可能是过时的，并不好看，我就尝试做了做外观特效，如图：
这是个动态称号，比较简单，PNG连帧 就搞定了。会点PS就简单了 还给几个养服大佬也定做了几个。
这只是个起因，然后我就想到了小时的梦想：上课的时候幻想自己给游戏做技能。
然后就入到了坑里来。
以前没接触过，但听老G说，这个端应该是目前还算完整的。079的5转技能也是后期大佬 通过原职业骑士团的技能修改来的。
但也是如此，基本可以继续用来开以旧新研的技能空缺就几乎没有了。
索性我就想自己新开ID头，完全新增技能。
开始的时候，刚好遇到这个端有个严重BUG，老G上个赛季用的 5转被动技能，放在这个新端里，会直接闪退。
这是原本大佬修改骑士团的被动，但是会闪退
然后我边新开1113将技能全数复制，修改前置ID，并且把所有相关主动技能 触发目标技能也同时修改，解决了这个BUG
起码说明，新开ID，创建自己的技能理论上应该是可以的。
期初 我也只是修改了技能特效，想让技能变的更炫酷一点
然后，遍尝试自己创造技能。
这是个新起的编号文件。
到这里看似都没出现什么问题。其实问题就出在这之后了。
游戏里，我可以获得到这个技能，但是就是无法释放，跟个被动技能一样，点了没有任何反应。也没有提示。
既然主动不行，我就尝试能不能先搞被动，因为之前的1113新开ID里的被动 都可以正常使用。
然后我就做了尝试
类似这样，新加入了3个法系职业的 被动。
然后我又又叒遇到了问题，我竟然发现，法术技能是不能触发被动效果的，这一下就很让我苦恼
我直接复制了一个物理系职业技能，触发的被动（没改），只改了前置ID，
可以正常使用，可以正常触发物理被动。
然后我只删除了物理伤害，改成mob魔法伤害，被动就不触发了。
反之，我将原魔法技能，删去魔法伤害 加入物理伤害，也不会触发物理被动。
到这里我的问题应该也描述的差不多了，希望能碰到有缘的大佬，来指点指点。
想为小时候的自己制作技能梦想圆一下。

简单来说的话，就是每个技能是通过硬编码形式在客户端内进行判断的，即
伪代码：
if (技能ID==1003) {
// 执行 圣甲术
}
如果你的期望是自行增加新的技能，那除改造已有效果的旧技能，就只剩改MapleStory.exe了
（如果你愿意花大功夫解析汇编的话）
