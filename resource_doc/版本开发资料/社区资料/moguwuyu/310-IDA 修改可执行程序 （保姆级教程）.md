IDA 修改可执行程序
使用 IDA 可以直接修改可执行程序中某些地址处的字节数据，并在修改后保存为新的 EXE / DLL，使改动永久生效。
这种方式适合在不借助额外开发工具的情况下，完成一些简单的基址、常量或指令修改。对于小范围 Patch 来说比较直观，也方便快速验证效果。
不过它的局限性也比较明显：更适合处理简单的静态修改。如果涉及复杂逻辑、动态判断、Hook、代码注入、运行时控制等内容，仅依靠 IDA 直接 Patch 往往不太够用，通常还需要配合 DLL 注入、补丁程序或其他开发方式来实现。

直接使用 IDA 对可执行程序进行 Patch，是逆向分析中非常基础但也非常实用的一项能力。
对于一些简单的功能修改、条件跳转绕过、数值调整或者快速验证思路来说，这种方式往往比重新编写 Hook 或 DLL 注入更加直观，也更容易快速看到效果。
不过随着修改内容逐渐复杂，仅依靠静态 Patch 往往会变得越来越吃力。很多时候，一个简单的功能改动背后可能涉及大量运行时逻辑、状态同步、资源加载甚至网络行为，这时候就需要结合 Hook、DLL 注入、代码注入或更完整的开发方案来实现。
但无论后面走到哪一步，理解并掌握这种最基础的字节级修改方式，依然是学习逆向与客户端修改过程中非常重要的一环。
