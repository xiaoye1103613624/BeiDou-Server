# OrzRepacker1.X 功能介绍——搜索

> 来源：https://moguwuyu.com/d/125
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

选择你要搜索的节点，然后按ctrl+f呼出搜索面板，搜索功能会自动往下搜索
目标：要搜索的内容
名称：在节点名里进行匹配（注意，道具名是节点name的值，而不是节点名）
String值：在节点值里进行匹配
完整匹配：匹配对象必须完全等于目标才行
忽略大小写：匹配时不需要大小写一致（即使是完整匹配）
搜选中：只搜索选中项及其所有子节点
搜全局：搜索整个树里的节点
搜索功能是绑定视图的，如果你要搜索右侧的树节点，需要先点击右侧的树节点区域，再进行操作
自动解析IMG，在搜索的过程中如果遇到未解析的 img（加载但从未展开过的 img），自动解析该 img，并深入搜索；解析 img 会增加内存占用，如果你只是想找到某个 img 的话，建议不要勾选这个。
在搜索结果界面，你可以在输入框输入文字进行进一步过滤（ctrl+f会自动聚焦到输入框）
可以点击标题栏进行排序
双击搜索结果会自动跳转到该节点
