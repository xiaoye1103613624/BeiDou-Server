# 关于北斗数据库无法初始化的问题

> 来源：https://moguwuyu.com/d/280
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

今天尝试初始化北斗的时候报了数据库错误
Statement violates GTID consistency: Updates to non-transactional tables can only be done in either autocommitted statements or single-statement transactions, and never in the same statement as updates to transactional tables.
好像只有比较新的数据库版本会这样
由于北斗使用 flyway 维护数据表，不能轻易修改以往的 sql 语句（会影响到所有老用户）
因此找了个临时的解决办法，
仅针对初始化失败的人
先打开数据库管理软件，将旧的
beidou
数据库中的数据表都删了，恢复一个空的数据库状态
然后执行查询语句临时禁用GTID
SET GLOBAL GTID_MODE = ON_PERMISSIVE;
SET GLOBAL GTID_MODE = OFF_PERMISSIVE;
SET GLOBAL GTID_MODE = OFF;

SET GLOBAL ENFORCE_GTID_CONSISTENCY = OFF;
然后启动北斗服务端完成数据库的初始化
待初始化完成后，自行选择是否恢复 GTID
SET GLOBAL ENFORCE_GTID_CONSISTENCY = ON;

SET GLOBAL GTID_MODE = OFF_PERMISSIVE;
SET GLOBAL GTID_MODE = ON_PERMISSIVE;
SET GLOBAL GTID_MODE = ON;
