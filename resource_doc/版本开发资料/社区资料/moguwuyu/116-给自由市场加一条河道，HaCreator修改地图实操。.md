# 给自由市场加一条河道，HaCreator修改地图实操。

> 来源：https://moguwuyu.com/d/116
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

看了B站大佬惊惊喵喵的自由市场，感觉好好看：
https://www.bilibili.com/video/BV1qsq8BMErN
虽然有点花里胡哨吧，但是这条河的感觉是真挺不错的，就想着也复刻一下，就去找地图相关的资料。
又正好看到B站上一个比较火的服的自由市场，感觉简单但也是有一条河，就像是这样，也是我修改后的结果：
那这是怎么实现的呢？
首先你要有原wz客户端，因为HaCreator打不开img的客户端。
打开HaCreator选择客户端地址，然后点击Initialize。
wz这里选择9100000000 点击Load。
然后根据图示，打开后在软体的右侧有一个Background，点击它，再往下翻，点击nautilusPort。里面的8就是河面，当然里面各个文件夹里都有不同的河道类型，个人觉得这个比较好看哈哈。
选择8以后直接拉到自由市场的地面下合适的位置，然后对河道素材点击右键，出现Edit this instance...，点击之后出现下图。
这个图里面的设置就是刚刚好的，点击OK就可以了。
记得要勾选Front Background，这是前景，不勾选河道就会被地砖挡住啦。Parallax X -5 这是河道河流速度，这个速度我是觉得刚刚好。
Type里选择Horizontal MovingCopies就是水平移动，河道就应该是水平移动的。
然后，注意看，一定要把图中标记的蓝色的线给拉下来，像图中这样！这是地图的最低点线，如果高了，你的河道会被状态栏给挡住，所以可以直接把这条蓝色的线拉到地砖最底部，这样你的河道也就能看到啦，而且其实拉低后观感不受影响的！
好了，改完以后就可以在软体上方Tools里点击MapSimulation预览啦，会发现地图最下面有河道移动啦！
最后在上方左上角倒三角点击Save to wz保存吧，导出img就用HaRepacker，大家应该都会啦。
