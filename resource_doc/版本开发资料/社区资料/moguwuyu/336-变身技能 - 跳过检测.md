**#1楼**

一下的代码是能让你在没有变身的情况下使出变身技能。
尤其是那些玩海盗王不然就是风行者的，变身后看不到自己商店的穿着。
代码框架来与Teto的Kaentake.
// Snatch & Demolition without Transformation
// Verified: CUserLocal::DoActiveSkill_MeleeAttack
PatchNop(0x0096964F, 2); // Nop 'jz short loc_969670' (morph check error)
Patch1(0x0096966A, 0xE9); // Change 'jz loc_96950C' to 'jmp loc_96950C' (always success)
Patch4(0x0096966A + 1, 0x0096950C - (0x0096966A + 5));
Patch1(0x0096966A + 5, 0x90);

// Shockwave (Marauder 5111006 / TB 15111003) without Transformation
// Verified: CUserLocal::DoActiveSkill_MeleeAttack
Patch1(0x009695A5, 0xE9); // Change 'jnz loc_96950C' to 'jmp loc_96950C'
Patch4(0x009695A5 + 1, 0x0096950C - (0x009695A5 + 5));
Patch1(0x009695A5 + 5, 0x90);

// Thunder Breaker skills without Transformation
// Verified: CUserLocal::DoActiveSkill_MeleeAttack
Patch1(0x0096963A, 0xE9); // Change 'jg loc_96950C' to 'jmp loc_96950C'
Patch4(0x0096963A + 1, 0x0096950C - (0x0096963A + 5));
Patch1(0x0096963A + 5, 0x90);

// Wind Breaker Eagle Eye follow-up skills bypass
// Verified: CUserLocal::DoActiveSkill_WeaponBooster
Patch1(0x009696FA, 0xEB); // Change 'jz short loc_96972B' to 'jmp short loc_96972B' (skip error)

// TB Transformation (15111002) & WA Eagle Eye (13111005) map restriction bypass
// Verified: CUserLocal::DoActiveSkill_MeleeAttack & DoActiveSkill_WeaponBooster
Patch1(0x009695E4, 0xEB); // Change 'jnz loc_96950C' to 'jmp short loc_96950C' (MeleeAttack)
Patch1(0x009695E5, 0x26);
Patch1(0x00969782, 0xE9); // Change 'jnz loc_969A33' to 'jmp loc_969A33' (WeaponBooster)
Patch4(0x00969782 + 1, 0x00969A33 - (0x00969782 + 5));
Patch1(0x00969782 + 5, 0x90);
