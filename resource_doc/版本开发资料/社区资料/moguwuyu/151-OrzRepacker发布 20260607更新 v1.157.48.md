**#1楼**

OrzRepacker 是一款用 Java 开发的 wz 编辑器，它的定位是开发给自己用的小工具。
相比传统 HaRepacker 而言，它不仅支持wz文件还支持直接打开img、xml文件，支持加载目录
有自己特色的 xml 导出格式（传统服务端 xml + png、mp3资源文件分离式导出）
有一些实用的小功能，包括但不限于
修改密钥
多视图（可同步节点的展开操作和收缩操作）
String 节点汉化
图片嗅探
图片对比（定位不同版本的图片差异）
outlink 图片替换
排序并改名（将无序的5、4、1、3这样的节点列表排序并重命名成1、2、3、4）
批量删除（批量删除指定名称的节点）
图片格式（批量修改图片格式）
图片缩放（批量放大或缩小图片）
已知问题
部分用户反馈在Win11家庭版上无法运行该软件，更换为专业版可解决，目前暂不清楚导致这个问题的原因
