遇到过的。你是不是最近启动过高版本的冒冒？这种现象很可能是注册表里放了一些高版本独有的配置信息，所以打开低版本的时候发生了错误。
优先建议清理一下注册表
。优先删Wizet，如果还是启动不起来，找找别的像是N社留下的注册表信息也删了。
(Win+R Regedit :  计算机\HEKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Wizet)
当然，
除了清理注册表
，同时也有一些别的泛用的处理方式：
1.显示器帧率设置60Hz；
2.显示设置-缩放与布局-更改文本、应用等项目的大小设置100%；
3.尝试不同的显示器分辨率；
4.兼容性启动；
5.管理员模式启动。
祝你早日解决。
