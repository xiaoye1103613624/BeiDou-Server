谢谢你我弄好了。就是注册表的问题。下面全删了重新安装就行了。不保证其他服还能玩 XD
reg query HKLM /s /k /f "Wizet"
reg query HKCU /s /k /f "Wizet"
reg query HKLM /s /k /f "maplestory"
reg query HKCU /s /k /f "maplestory"
reg query HKLM /s /k /f "nexon"
reg query HKCU /s /k /f "nexon"
