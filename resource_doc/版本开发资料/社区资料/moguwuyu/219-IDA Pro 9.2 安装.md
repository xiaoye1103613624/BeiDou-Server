**#1楼**

安装包下载
https://pan.quark.cn/s/6d99355f1146
提取码
9wF3
安装包来自于互联网，由于带绿色化性质，自行决定是否使用
安装的时候有个选项是安装 Python3，如果你的电脑没有安装过 Python3 的话就要保持勾选
安装完成后将 keygen-v2.py 复制到 IDA Pro 目录
代码登录后可见
运行管理员模式的 cmd
先测试一下 python 命令是否能用
代码登录后可见
如果输出的是Python的版本号，说明安装完成了，否则就要重启一下电脑让环境变量生效
进入软件目录并执行激活命令，
注意
这里的日期必须设置得比当前日期早，否则激活了也会提示激活码未生效
代码登录后可见
