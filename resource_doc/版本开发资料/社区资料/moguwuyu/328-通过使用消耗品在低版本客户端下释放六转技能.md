# 通过使用消耗品在低版本客户端下释放六转技能

> 来源：https://moguwuyu.com/d/328
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

通过以下操作，可以绕过客户端主程序对技能ID硬编码限制（否则只能添加被动技能，主动技能执行不生效），直接释放自定义技能
1：维护新技能，如技能 ID 1321018，维护到客户端wz，服务端wz
2：新增消耗品，如 2430125 、2430126，一个触发6转，一个触发五转
3：新增后台GM命令，可以按照技能类别去区分，方便测试，技能释放逻辑（先组攻击上下文，再按固定顺序，explosion，攻击包，结算前飘字，结算伤害，结算后补飘字，解锁动作）
4：测试普通技能GM命令：!sx 技能ID 5
5：测试六转技能GM命令：!six 1 技能ID 2
6：将消耗品执行指向到指定技能，消耗品有个属性script，这个属性可以放你新增的技能ID
备注：技能释放逻辑依然不够完善，仅供参考
可以正常放到键位上执行
