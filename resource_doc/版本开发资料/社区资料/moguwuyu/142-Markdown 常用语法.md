**#1楼**

Markdown 中 ~ 和 * 是特殊符号，要正常输出这些符号的话，需要在符号后面加空格，避免被转义，或者使用行内代码
标题
### 标题
#
代表标题字号、等级（对应html的H1、H2，数字即
#
数量），
#
越多，字体越小，我一般是三级标题开始
代码
有两种格式，一种是代码块（其中java是代码语言，可以根据需要修改），多行代码必须使用代码块
```java
code
```
一种是行内代码
`code`
多层代码块可以使用更多的 ` 来避免内容被提前解析掉，比如
````markdown
```java
...code
```
````
输出结果就是
```java
...code
```
这个点是键盘左上角波浪线上那个点

折叠内容

>! 折叠内容
只要没有空行隔开，都会收起来
