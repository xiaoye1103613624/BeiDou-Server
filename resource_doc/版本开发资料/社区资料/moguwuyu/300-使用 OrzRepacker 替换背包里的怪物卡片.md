# 使用 OrzRepacker 替换背包里的怪物卡片

> 来源：https://moguwuyu.com/d/300
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

需要使用最新的 v1.152.46
用 Orz 加载 0238.img 或者 Item.wz，在该 img 上右键，使用 RawToIcon 功能
该功能会将 iconRaw 节点的图片复制到同一个 List 下的 icon 节点
iconRaw的图片高度为38，而背包的高度为32，你可以视情况使用图片缩放功能（图片缩放会导致图片模糊）
我们只缩放 icon 节点的图片，因此名称填入 icon，缩放比例填写0.85
这样缩放后刚好是32的高度
接着，同样在 img 上右键，使用“修改图片origin”功能来批量调整 icon 的偏移（如果不调的话，默认偏移是
0, 32
处于背包格子的最左侧）
X偏移为
(32 - 22) / 2  =  5
取负数表示向右偏移
Y偏移默认 32
这样偏移就调整好了
消耗类道具的 consumeOnPickup 如果是1的话，在捡起该道具的时候服务端会自动将其使用掉，导致无法进入背包
同样的右键 img 使用“修改int值”功能，批量修改该节点
除了consumeOnPickup节点以外，你可能还需要将 tradeBlock 节点改为 0，以允许其交易，only 可能也要改为 0 来移除“唯一”属性，我不记得了，自己尝试一下吧。
