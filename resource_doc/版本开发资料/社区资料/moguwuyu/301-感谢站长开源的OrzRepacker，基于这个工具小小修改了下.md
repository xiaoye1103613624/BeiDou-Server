# 感谢站长开源的OrzRepacker，基于这个工具小小修改了下

> 来源：https://moguwuyu.com/d/301
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

1.支持官方.ms文件，BC7（伪实现，自动降级DXT5），可以自由保存.ms文件或者.wz文件（来源HaRepackerResurrected）
2.支持属性含义（tools目录下json文件可自由维护）
3.右键添加同节点复制，复制后，在当前节点创建同样节点（后缀数字），如effect，创建5个同样的，就是effect1到effect5
4.多线程优化，巨幅提升outlink速度，修补9000张图片无错，只需要2秒，建议电脑内存8G以上
5.批量修改，可以快速修改节点下面的属性，如批量修改坐标，等基础的，中间面板可指定勾选
6.旧版本技能特效图片修改支持，一些老版本冒险岛，如果用工具修改冒险家职业的技能，进游戏放修改的技能就崩溃报错，勾选这个（实现图片list.wz加密）就能完美释放移植的技能了，CMS125测试没问题，听说火炮之后的新职业要用正常的，请不要勾选这个，自行测试下（功能源自SLFCG Repacker，C#改java代码重构了）
7.动画预览，可以右键 快速预览该节点下的动画（多张png算动画），右键可以小窗查看大图
8.复制节点（可多选），复制后，可粘贴为XML，也可以把XML修改后粘贴回，忘记那些节点支持了，图片格式和一些属性是支持的
9.右键图片大小，可以批量修改节点下方的图片大小，逻辑为先按目标宽度等比缩放，高度超出部分上下对称等量从边缘裁剪，始终居中不拉伸、不偏位
