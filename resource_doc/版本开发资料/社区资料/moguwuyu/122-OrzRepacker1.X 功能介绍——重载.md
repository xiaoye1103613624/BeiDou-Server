# OrzRepacker1.X 功能介绍——重载

> 来源：https://moguwuyu.com/d/122
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

Wz 文件、Img 文件和 Xml 文件 这三种节点的右键菜单里均有个重载菜单
重载即重新加载，指的是放弃当前的一切修改重新从磁盘加载文件。
因此
重载会使用顶部菜单栏的密钥
重新打开选中的文件。
于此同时重载功能会触发程序的内存回收
常见使用场景有两个：
一是对节点进行了编辑，但是突然不想要了
二是加载文件时候选错了密钥，只需要重新选择正确的密钥，重载一下文件节点就好了
加载文件时选择了错误的密钥，打开文件后是乱码
选择正确的密钥后点击重载
打开后正常了
