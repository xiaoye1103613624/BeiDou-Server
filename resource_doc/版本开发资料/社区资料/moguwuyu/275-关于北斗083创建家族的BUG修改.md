关于北斗083创建家族的BUG，修改如下：
找到GuildOperationHandler.java这个文件里面的0x02，修改0x02到0x05之间的代码如下：
if (mc.getGuildId() > 0) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message1"));
                    return;
                }
                if (mc.getMeso() < GameConfig.getServerInt("create_guild_cost")) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message2"));
                    //mc.dropMessage(1, "You do not have " + GameConstants.numberWithCommas(GameConfig.getServerInt("create_guild_cost")) + " mesos to create a Guild.");
                    return;
                }
                String guildName = p.readString();
                if (!isGuildNameAcceptable(guildName)) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message3"));
                    return;
                }
                // 检查玩家是否在队伍中
                if (mc.getParty() == null) {
                    // 自动创建队伍
                    if (!Party.createParty(mc, true)) {
                        mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message6"));
                        return;
                    }
                }
                // 检查队伍人数是否足够
                int requiredMembers = GameConfig.getServerInt("create_guild_min_partners");
                if (mc.getParty().getMembers().size() < requiredMembers) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message4"));
                    return;
                }
                // 获取队伍中的所有成员
                Set<Character> eligibleMembers = new HashSet<>();
                for (PartyCharacter pc : mc.getParty().getMembers()) {
                    Character chr = mc.getWorldServer().getPlayerStorage().getCharacterById(pc.getId());
                    if (chr != null && chr.getMapId() == mc.getMapId() && chr.getLevel() >= 10 && chr.getGuildId() == 0) {
                        eligibleMembers.add(chr);
                    }
                }
                if (eligibleMembers.size() < requiredMembers) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message5"));
                    return;
                }
                // 扣除创建家族的金币
                int cost = GameConfig.getServerInt("create_guild_cost");
                mc.gainMeso(-cost, true, false, true);
                // 创建家族
                int guildId = Guild.createGuild(mc.getId(), guildName);
                if (guildId == 0) {
                    mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message8"));
                    return;
                }
                // 设置玩家为家族成员
                mc.getMGC().setGuildId(guildId);
                mc.getMGC().setGuildRank((byte) 1); // 领导者
                mc.getMGC().setAllianceRank(5);
                // 添加其他成员到家族
                for (Character chr : eligibleMembers) {
                    if (chr.getId() != mc.getId()) {
                        chr.getMGC().setGuildId(guildId);
                        chr.getMGC().setGuildRank((byte) 5); // 普通成员
                        chr.getMGC().setAllianceRank(5);
                        Server.getInstance().addGuildMember(chr.getMGC(), chr);
                        chr.saveGuildStatus();
                        chr.getMap().broadcastPacket(chr, GuildPackets.guildNameChanged(chr.getId(), guildName));
                        chr.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message9", guildName));
                    }
                }
                // 保存玩家的家族状态
                mc.saveGuildStatus();
                // 添加家族成员到在线列表
                Server.getInstance().setGuildMemberOnline(mc, true, c.getChannel());
                // 发送家族信息给玩家
                c.sendPacket(GuildPackets.showGuildInfo(mc));
                // 增加家族GP
                mc.getGuild().gainGP(500);
                // 广播家族创建成功的消息
                mc.getMap().broadcastPacket(mc, GuildPackets.guildNameChanged(mc.getId(), guildName));
                mc.getMap().broadcastPacket(mc, GuildPackets.guildMarkChanged(mc.getId(), mc.getGuild()));
                // 提示玩家家族创建成功
                mc.dropMessage(1, I18nUtil.getMessage("GuildOperationHandler.handlePacket.message10", guildName));
                // 重新生成玩家
                respawnPlayer(mc);
                break;

**#9楼**

我找到北斗冒险岛创建家族困难的原因了：
1、所有人到图后，不要（不能）组队，都要是散员状态，同图即可
2、所有人在创建者发布创建家族后，游戏正上方会弹出一张图片，由于很慢，要等待，且不能乱操作
3、大约过3秒，图片才会显示出【同意】按钮。所有人都要点同意，只要有一个人出错，系统就会报错。而不是指明有人未同意
