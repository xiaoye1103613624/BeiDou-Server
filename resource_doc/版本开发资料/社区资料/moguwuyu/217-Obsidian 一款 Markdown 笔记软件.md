# Obsidian 一款 Markdown 笔记软件

> 来源：https://moguwuyu.com/d/217
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

这是一款开源免费的笔记软件，所有笔记都保存在本地，没有隐私风险
你可以纯本地使用，或者用 git 来同步或者使用官方的付费同步
我是用 Github 同步的
先在 Github 上创建一个私有仓库
将这个空仓库克隆到本地，然后用 ob 初始化该目录
接着安装插件，设置——选项——第三方插件——社区插件市场——浏览（这个页面会访问Github，部分地区需要科学上网）
搜 git
配置一下，它就会自动帮你执行 pull、commit 或者 push 等操作，也可以在ob的命令行里手动执行
不只是笔记，软件的配置、插件什么的都会同步到 git 上，要在其他机器使用，只需要 clone 仓库到本地，用 ob 打开即可，非常方便
ob 还有很多强大的地方，是一款非常不错的软件。
