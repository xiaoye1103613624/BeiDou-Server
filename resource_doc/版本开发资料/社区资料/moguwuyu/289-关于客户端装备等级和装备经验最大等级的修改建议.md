# 关于客户端装备等级和装备经验最大等级的修改建议

> 来源：https://moguwuyu.com/d/289
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

北斗有自定义装备升级的代码，但是原版只有永恒系列装备有升级系统。
当自定义装备升级时装备详情页会有错误：
详情举例：当设置use_equipment_level_up为10时，所有装备均可升级自10级，但是当装备升级至10级时，道具详情页仍然显示10级，道具经验永远显示0%，而非双MAX。
解决办法：修改所有能升级的道具wz。
具体操作：根据你设置的最大等级（以3举例）修改info - level - info节点增加1-3节点，在3节点设置经验值0即可修复显示错误。
