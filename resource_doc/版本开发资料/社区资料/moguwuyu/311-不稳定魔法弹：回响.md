# 不稳定魔法弹：回响

> 来源：https://moguwuyu.com/d/311
> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

在“不稳定魔法弹”被写进魔法学院教材附录之后，那位最初施放出此法术的新手魔法师并没有因此受到导师们的认可。
恰恰相反。
学院认为，他虽然成功开创了一种全新的魔法弹变体，但整个过程缺乏理论依据、缺乏稳定复现、缺乏安全规范，并且最重要的是——缺乏悔改态度。
于是，在连续三次将考试用魔法弹打成螺旋线、折返线和一条疑似正在逃跑的曲线之后，他被导师们一致建议外出进修。
至于去哪进修，学院内部产生了激烈争论。
有人建议送他去高等奥术塔，系统学习弹道控制。
有人建议送他去元素学院，重新学习魔力凝聚。
还有人建议直接送他去杂物间，让他在那里和扫帚互相反省。
最后，一位年迈导师提出了一个大胆而不负责任的建议：
“既然他的问题不是不会施法，而是不知道为什么能施法成功，那也许应该让他去找一个同样不知道为什么能成功的专家。”
于是，新手魔法师踏上旅途，去寻找传说中的食人魔魔法师——阿格隆·碎石者。
找到它并不困难。
毕竟，能在战场上把同一个法术莫名其妙施放两次、三次，甚至更多次的双头食人魔，并不常见。
困难的是，让它听懂自己的问题。
“我想学习你的多重施法。”新手魔法师认真地说道。
食人魔魔法师的左脑袋沉思片刻，右脑袋也沉思片刻。
然后左脑袋问：
“哪个施法？”
右脑袋问：
“多重哪个？”
这场教学从一开始就充满希望地走向了灾难。
食人魔魔法师解释说，多重施法的关键在于“再来一次”。至于为什么会再来一次，它不知道。什么时候会再来一次，它也不知道。能不能控制，它更不知道。
但它坚信，只要足够自信，魔法就会自己不好意思只发生一次。
新手魔法师听完后大受震撼。
他在笔记本上郑重写下：
高级施法理论第一条：
如果一个法术只发生了一次，可能是因为它不够努力。
在随后的训练中，食人魔魔法师不断示范。
火球术。
一次。
两次。
三次。
有时甚至连它自己都惊讶地看着第三颗火球飞出去，然后高兴地鼓掌。
新手魔法师试图模仿。
他举起法杖，念出咒语，释放出一枚不稳定魔法弹。
魔法弹照例没有沿直线飞行。
它先向左漂移，又猛地向右抽搐，接着在空中绕了一个毫无意义的小圈，最后以一种令人不安的角度砸中了目标。
食人魔魔法师两个脑袋一起点头。
“好。”
“很蠢。”
“很有前途。”
新手魔法师深吸一口气，等待第二发魔法弹出现。
然而什么都没有发生。
没有多重施法。
没有额外弹道。
没有新的魔法弹。
只有第一枚魔法弹飞过之后，在空气中留下的一串摇摇晃晃的蓝色残光。
正当食人魔魔法师准备宣布这次教学非常成功，因为至少没有炸到自己时，那串蓝色残光忽然轻轻颤动了一下。
随后，一枚半透明的魔法弹从残光中慢吞吞地钻了出来。
它看起来不像是被重新施放出来的。
更像是上一枚魔法弹的影子，在短暂犹豫之后决定：
“我也要打一下。”
第二枚魔法弹沿着第一枚魔法弹留下的混乱轨迹飞行，但并没有完全重复。它像是在模仿，又像是在回忆，时而跟随原本的路径，时而偏离出去，最后在一阵极不专业的抖动后，同样命中了目标。
新手魔法师愣住了。
食人魔魔法师也愣住了。
左脑袋说：
“这是多重施法。”
右脑袋说：
“不像。”
左脑袋想了想：
“但是打中了。”
右脑袋立刻表示赞同：
“那就是。”
从那天起，新手魔法师掌握了一种全新的技巧。
它既不是标准的多重施法，也不是普通的重复攻击。
食人魔魔法师的多重施法，是在一次施法中凭借惊人的运气额外施放同一个法术。
而他的魔法回响，则是让已经飞出的魔法弹在命中之后，于残留的魔力轨迹中产生一次延迟的回应。
学院导师后来试图分析这种现象。
他们认为，这可能是由于不稳定魔法弹在飞行过程中产生了过量的奥术扰动，使路径中的残余魔力形成了短暂的自激结构。当主法术命中目标后，残余轨迹会在目标魔力反馈的影响下重新收束，并形成一次较弱但完整的二次打击。
新手魔法师听完后沉默了很久。
然后他在教材附录旁边补了一行注释：
魔法弹飞出去以后，如果它觉得刚才表现得不错，可能会回来再表演一次。
食人魔魔法师对此评价很高。
它的左脑袋说：
“很聪明。”
右脑袋说：
“不像。”
左脑袋补充道：
“所以更好。”
如今，这门法术被称为“魔法回响”。
许多法师坚持认为，它与食人魔魔法师的多重施法存在本质区别。
多重施法依靠的是运气。
魔法回响依靠的是残留轨迹、魔力反馈、延迟共振，以及复杂到没人愿意认真验证的奥术模型。
但那位新手魔法师本人对此有一个更简单的解释：
“蓝胖子教我再放一次。”
“但我没学会。”
