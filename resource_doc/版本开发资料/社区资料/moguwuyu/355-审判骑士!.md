# 审判骑士!

> 站点：蘑菇物语(moguwuyu.com) · Flarum 改端技术论坛

**#1楼**

下面是小故事环节：
在圣地最古老的传说中，圣骑士的力量并不只来自手中的剑，也不只来自厚重的铠甲。
真正的圣骑士，必须在黑暗面前保持信仰，在绝望之中守住誓言。
当他们以坚定之心挥动武器时，那份信念会穿过战场的喧嚣，抵达女神所在的光辉殿堂。
据说，女神不会轻易回应凡人的呼唤。
但当一名圣骑士为了守护同伴、驱散邪恶而战时，她的目光便会落在他的剑锋之上。
那一刻，圣光会在武器中苏醒。
一次普通的攻击，可能引来女神的审判。
灵魂之刃会从光芒中斩落，撕裂敌人的防线；灵魂突刺会贯穿黑暗，给予邪恶最终的惩戒。
随着圣骑士信仰不断坚定，女神赐予的审判也会变得更加强大。
最初，那只是转瞬即逝的一道圣光。
后来，它会化作真正的灵魂之刃。
再后来，审判会如长枪般刺穿战场，让敌人明白：圣骑士的每一次挥击，都可能是神意的降临。
于是，人们将这种力量称为——女神审判。
它并非单纯的攻击技巧。
而是圣骑士与女神之间无声的誓约。
“真正的审判，并不只来自剑锋，也来自女神的凝视。”
