经过实操，确实能取消遮挡面板，但是不会显示加点按钮以及自动分配按钮，所以还需要其他地方的改动。
以下为完整方法：
`// Patch 1: OnCreate 调用点 - 跳过 is_beginner 检查
// 008C293F: 0F 84 -> 90 E9 (je -> nop; jmp)
Memory::WriteByte(0x008C293F, 0x90);
Memory::WriteByte(0x008C2940, 0xE9);
// 2. OnCreate 等级检查: ja -> jmp
Memory::WriteByte(0x008C53F4, 0xEB);
// 3. Draw 等级检查: ja -> nop; jmp
Memory::WriteByte(0x008C61A8, 0x90);
Memory::WriteByte(0x008C61A9, 0xE9);
// 4. Draw 新手职业检查: jne -> nop nop
Memory::WriteByte(0x008C6376, 0x90);
Memory::WriteByte(0x008C6377, 0x90);
// 5. Update 按钮可见性检查: ja -> jmp
Memory::WriteByte(0x008C7A70, 0xEB);`
