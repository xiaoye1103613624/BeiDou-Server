**#1楼**

没有编程知识，纯小白，研究了ijl15一段时间，感谢论坛大佬的教程，粘贴复制实现了BUFF倒计时:lol
也是因为看到B站有人用什么全民稳如泰山啥的，就想也去实现这个效果，就开始找资料，最先想到的就是群里有个083的汉化辅助，里面有稳如泰山的效果。
接着就去找这个辅助的源码，在github里有，附件已经给大家附上。
打开源码后啥也看不懂，但也还是找到noPlayerKnocbackAddr不被击退，地址 0x007A637F。
然后看实现方法，这是辅助源码的：
void MainForm::cbNoPlayerKnockback_CheckedChanged(Object^  sender, EventArgs^  e) {
if (this->cbNoPlayerKnockback->Checked)
WriteMemory(noPlayerKnocbackAddr, 3, 0xC7, 0x00, 0x00); //mov [eax],00000000 [first 3 bytes]
else
WriteMemory(noPlayerKnocbackAddr, 3, 0xC7, 0x00, 0x01); //mov [eax],00000001 [first 3 bytes]
嘿，知道地址和方法了这不就直接抄就好了吗，所以就在ijl15里的：
在AddyLocations.h中新增
const DWORD noPlayerKnocbackAddr = 0x007A637F;
添加玩家无击退的目标地址👆
然后在Client.cpp找到Client::UpdateGameStartup下添加
Memory::WriteMemory(noPlayerKnocbackAddr, 3, 0xC7, 0x00, 0x00);
ok，生成构建，你就会发现实现了稳如泰山了，很简单吧！
但是有一个问题！！！二段跳不能用了，希望有大佬能解决一下！
