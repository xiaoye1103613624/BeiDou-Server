## 一、多服分离架构（Login / World / Channel / CashShop）

冒险岛服务端普遍采用**多服分离**架构。以 Valhalla 为例，分为四类服务进程，北斗/Cosmic 同样区分 LoginServer 与 ChannelServer：

### Login Server（登录服）
负责：账号登录、自动注册、EULA、PIN、世界(World)列表与状态显示（如"人数过多"）、世界/频道选择、创建/删除角色、迁移到频道服(migrate to channel)。

### World Server（世界服）
负责：统计在线人数、向登录服汇报状态、转发玩家上下线到各频道、广播好友/组队/公会事件、转发密语(whisper)、跨频道同步组队与公会、传播角色删除。

### Channel Server（频道服）
负责实际游戏逻辑：玩家可见/移动/聊天、传送门、加点、技能、背包、使用道具/卷轴/商城物品、掉落、宠物、NPC（可见/移动/对话/商店/造型师/仓库）、怪物（生成/移动/攻击/技能/死亡/重生/掉落/Boss血条）、组队副本(PQ)、交易、任务、反应堆(Reactor)、小游戏等。

### CashShop Server（商城服）
负责：列出商城物品、用不同货币购买。

> **北斗对应**：`org.gms.net.netty.LoginServer`（登录）与 `org.gms.net.netty.ChannelServer`（游戏频道）。一个 World 含多个 Channel，每个 Channel 是独立的 Netty 实例。详见 CLAUDE.md "Dual Network Layer"。

**开发模式技巧（Valhalla dev mode 思路）**：把四类服务跑在**单进程**里，用 localhost 互联、开启自动注册、调高经验/掉落倍率，方便单机测试。北斗也是单机即可启动登录+频道。

## 二、封包(Packet)结构基础

冒险岛封包是 **opcode + 数据体** 的二进制格式。MapleLib 的读写模型（与北斗 `net.packet.PacketWriter` 概念一致）：

### 读包（PacketReader）
```csharp
PacketReader reader = new PacketReader(receivedBytes);
short opcode = reader.ReadShort();        // 前 2 字节是 opcode
string message = reader.ReadMapleString(); // MapleString：先读 short 长度，再读对应字节
// 根据 opcode 分发处理
```

### 写包（PacketWriter）
```csharp
PacketWriter writer = new PacketWriter();
writer.WriteShort(0x01);                  // opcode
writer.WriteMapleString("Hello Maple");
// 发送 writer.ToArray()
```

**关键概念：**
- **opcode**：封包头部的 2 字节短整型，区分封包类型。分为 **SendOpcode（服务端发）** 和 **RecvOpcode（客户端发）**。
- **MapleString**：冒险岛特有字符串格式 = `short 长度` + UTF/ASCII 字节。
- **字节序**：小端(little-endian)。
- **加密**：客户端封包经过加密/解密层（北斗在 `net.encryption`，早期用 AES + 自定义 shuffle）。

> **北斗对应**：
> - opcode 定义在 `org.gms.net.opcodes`（区分 sent / received）；
> - 封包分发在 `org.gms.net.PacketProcessor`（维护 `Map<RecvOpcode, PacketHandler>`）；
> - 频道处理器在 `org.gms.net.server.channel.handlers.*`，登录处理器在 `org.gms.net.server.handlers.login.*`；
> - 加解密在 `org.gms.net.encryption`。
>
> **逆向参考**：opcode 在不同版本会变化。Valhalla 逆向 v28 封包时参考了 Vana(C++)、WvsGlobal、OpenMG 等项目，以及 RageZone 论坛的 idb 地址表。北斗(v83)的 opcode 已在源码中定义，移植高版本功能时需注意 opcode 不通用。

## 三、NPC 脚本聊天格式化代码（全 Java 系通用）

以下格式化代码在 NPC 对话脚本中通用（北斗的 `scripts-zh-CN/npc/*.js` 直接适用），出自 RageZone 社区整理：

### 文字颜色与样式
| 代码 | 作用 |
|------|------|
| `#b` | 蓝色文字 |
| `#d` | 紫色文字 |
| `#g` | 绿色文字 |
| `#k` | 黑色文字 |
| `#r` | 红色文字 |
| `#e` | 加粗 |
| `#n` | 取消加粗（恢复正常） |

### 动态内容引用
| 代码 | 作用 |
|------|------|
| `#h #` | 显示玩家名字 |
| `#t[itemid]#` / `#z[itemid]#` | 显示物品**名称** |
| `#i[itemid]#` / `#v[itemid]#` | 显示物品**图标** |
| `#c[itemid]#` | 显示玩家背包里该物品的**数量** |
| `#m[mapid]#` | 显示地图名称 |
| `#o[mobid]#` | 显示怪物名称 |
| `#p[npcid]#` | 显示 NPC 名称 |
| `#q[skillid]#` | 显示技能名称 |
| `#s[skillid]#` | 显示技能图标 |
| `#f[图片路径]#` / `#F[图片路径]#` | 显示 WZ 中的图片 |

### 选项与排版
| 代码 | 作用 |
|------|------|
| `#L[编号]#` | 选项**开始**（可点击选项） |
| `#l` | 选项**结束/关闭** |
| `#B[百分比]#` | 显示进度条 |
| `\r\n` | 换行 | 
| `\n` | 新行 |
| `\t` | 制表符（约 4 空格） |
| `\b` | 后退 |

**示例（选项菜单）：**
```javascript
cm.sendSimple("你想做什么？\r\n" +
  "#L0#查看商店#l\r\n" +
  "#L1#了解 #t2000000# 的用途#l");  // #t...# 自动显示物品名
```

> **北斗对应**：脚本通过 `AbstractPlayerInteraction`（即脚本里的 `cm`）与 Java 世界交互：`cm.sendNext()`、`cm.sendSimple()`、`cm.openShop()`、`cm.gainItem()`、`cm.warp()` 等。脚本引擎是 GraalJS，目录 `scripts-zh-CN/{npc,quest,portal,reactor,event,item,map}/`。
