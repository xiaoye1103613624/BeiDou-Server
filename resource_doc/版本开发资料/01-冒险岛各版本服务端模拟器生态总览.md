# 冒险岛各版本服务端模拟器生态总览

> 资料整理日期：2026-06-17
> 来源：各开源服务端项目的 GitHub README / Wiki（HeavenMS、Cosmic、Valhalla、Edelstein、Destiny、Moonlight、Orpheus、CMS143、TW113、MapleServer2 等）
> 用途：北斗(BeiDou)服务端二次开发参考，了解各版本改端的技术栈、定位与血缘关系

## 一、模拟器血缘关系（Pre-Big Bang 主线）

冒险岛私服模拟器有一条延续十多年的代码血脉，北斗(BeiDou)正是这条主线的最新分支：

```
OdinMS (2008，最早的开源 v62 服务端)
   └─ MoopleDev (v83，OdinMS 的重构延续)
        ├─ OrpheusMS (基于 MoopleDev rev116，v83)
        └─ MapleSolaxia (v83)
             └─ HeavenMS (2019，rev203+，v83，社区最流行)
                  └─ Cosmic (2021，Ponk 维护，v83，现代化重构)
                       └─ BeiDou 北斗 (本项目，GMS v83，Java21 + SpringBoot3 + Vue3)
```

**关键点：**
- 北斗的直接上游是 **Cosmic**，Cosmic 又源自 **HeavenMS → MapleSolaxia → MoopleDev → OdinMS**。
- 这条主线统一是 **Java 语言 + JavaScript 脚本（NPC/任务）**，所以脚本写法、目录结构、封包处理逻辑在整条血脉中高度相似。
- 阅读 HeavenMS / Cosmic 的源码和文档，对理解北斗的设计有直接帮助。

## 三、版本时代划分（重要分水岭）

冒险岛的开发资料会因"版本时代"差异巨大，搞清楚版本属于哪个时代很关键：

### 1. Pre-Big Bang（大爆炸之前，约 v83 及更早）
- 经典怀旧版本，v62 / v79 / v83 是私服最热门的三个版本。
- WZ 文件使用 **List.wz** 索引文件（大爆炸后取消）。
- 北斗、HeavenMS、Cosmic 都属于这一时代（v83）。

### 2. Big Bang 之后（约 v100+）
- 地图、职业、技能系统大改。
- v95（Edelstein）、v113（台服）、v143（国服）属于此时代。

### 3. 高版本（v200+）
- WZ 文件升级为 **.ms 加密格式**（约 v220+ 引入）。
- 客户端需通过 Steam（Depot Downloader）获取，如 Moonlight(v214)。
- 数据量极大，WZ dump 需用 HaRepacker Resurrected。

## 四、对北斗开发的实践建议

1. **参考 Cosmic 上游**：北斗 fork 自 Cosmic，遇到核心机制（封包、地图、任务引擎）不清楚时，优先对照 Cosmic / HeavenMS 源码，而非高版本或其他语言实现。
2. **版本一致性**：北斗是 v83，移植功能时优先找 v83 系（HeavenMS/Cosmic/Orpheus/Destiny）的实现，避免直接套用高版本逻辑。
3. **脚本通用性**：整条 Java 主线的 NPC 聊天格式化代码（`#b` `#i[itemid]#` 等）通用，详见《冒险岛封包与网络架构》文档。
4. **跨语言参考**：Valhalla(Go)、Edelstein(C#)、Destiny(C#) 适合用来理解"架构思路"（如四服分离），但具体 API 不能照搬。
