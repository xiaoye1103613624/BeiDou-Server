## 为何前几轮「修红」没根治

| 旧判断 | 实际 |
|--------|------|
| `is_correct` 对 BP51 无条件 jmp 永不成功 | Client_1 上 jmp 落到复用 ZF 的 `jz`，**原生已接受 17\|51**；钩子只是保险 |
| AbleToWear 对 112 仅 `if (r) return 1` | 护肩是 **call-orig-then-OK 无条件 return 1**；112 半吊子 |
| 红 = BP23 空「项链」底图叠在 (104,134) | 移到 slot7 `(38,101)` 后仍红 → **不是底图**，是 TSecType 红罩 |
| 只改坐标 / HitTest / extra-pendant 旗标 | 旗标能画图标，但 **锁失败仍染红 + 跳过属性** |

护肩为什么没事：BP20 是常规装备数组槽，**不走 BP51 那套 TSecType 失败分支**。

## 一分钟验证

1. **完全退出** `BeiDou.exe` 再开 Client_1  
2. 确认 `ijl15_pendant2_VERSION.txt` / 导出串含 **`PENDANT2_SHOULDER_MIRROR_20260726u`**  
3. 进图 → 装备栏：第二坠仍在 **slot7 (38,101)**，图标**正常色（不红）**  
4. 看角色能力 **运气 (10053+装备)**：记下装备加值（如 +515）  
5. `@第二坠 卸下`（或拖下 −51）→ 装备加值应 **−7**（STR/DEX/INT/LUK 各少 7；若有潜能再另计）

7. 护肩 / 主坠 / 腰带仍正常
