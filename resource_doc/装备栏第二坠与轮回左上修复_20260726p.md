## B. HitTest 补丁为何 n 无效（证据）

`BeiDou.exe` 反汇编：

```
0x00801214: 83 FE 30     cmp esi, 0x30   ; BP>48 跳过矩形
0x008013A1: 8B D6        mov edx, esi
0x008013A3: 83 FA 32     cmp edx, 0x32   ; while bp < 50
0x008013A6: 0F 82 ....   jb  loop
```

n 版常量：`kHitTestCmpLoopEnd = 0x008013A2`，写 `+2` → 改的是 **`FA`（ModRM）**，不是立即数 → 循环指令损坏。

且 `bp` 是 **部位号**（1-based）：`imm=0x33` 只保证测到 BP50；要测 **BP51** 需 **`imm=0x34`**（while bp\<52）。

- 装备：`1132300`「轮回碑石」，`islot=Po`，`cash=1`；服务端 `EquipSlot.BELT=-50`。

- 结果：图标画在窗体原点；点图标 HitTest 对不上 → **不能选/不能卸**。
