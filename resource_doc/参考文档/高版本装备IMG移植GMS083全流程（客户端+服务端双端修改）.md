# 高版本装备IMG移植GMS083全流程（客户端\+服务端双端修改）

> 工具：HaRepacker\-R、WzComparerR2、NMS/HeavenMS 服务端数据库、Item\.wz/Character\.wz/Str\.wz，**高版本多指 v095\+、KMS 后续装备，IMG 节点结构、字段大量新增，不能直接导入**
> 
> 

## 一、前期准备（移植前校验）

1. **拆分资源包**
高版本装备资源分两处：

    - 外观 IMG：`Character.wz/对应分类(Coat/Hair/Weapon等)/装备ID.img`（模型、动作帧、坐标）

    - 属性数据：`Item.wz/equip/装备分类ID/装备ID.img`（攻防、等级、属性、穿戴限制）
    用 HaRepacker 打开高版本 WZ，单独导出**目标装备 2 个 IMG（Character\+Item）**，保存备用。

2. **确定可用 ID**
遵循 083 编码规则（3 位分类 \+ 性别 \+ 流水），在 083 Item\.wz 里找**空白未占用 ID**，不能沿用原高版本 ID（高版本 ID 段很多超出 083 数据库、WZ 索引范围）。

    > 例：原装备 ID1305999（高版本单手剑）→改成 083 空闲 1302555。
    > 
    > 

3. **区分废弃字段**
高版本独有字段：潜能 option、附加潜能、星星强化、托德、套装隐藏属性、专属特效节点，**083 客户端不识别，必须全部删除**，否则客户端闪退、装备白图报错。

## 二、客户端 WZ 分步修改（核心 5 步）

### 步骤 1：修改 Character\.wz（外观 IMG）

1. 打开 GMS083 原版 Character\.wz（选 GMS83 加密密钥），进入对应装备目录（武器→Weapon/130、上衣→Coat/104）。

2. 新建【新 ID\.img】，把高版本 IMG 内**有效节点复制过来**，批量删除高版本多余节点：

    - 删除：`option、star、potential、exOption、setOption、effectExtra`等高版本专属参数

    - 保留：stand/walk/jump/attack 动作帧 Canvas、xy 偏移、delay 帧延迟、镜像标记

3. **帧尺寸修正**：高版本素材分辨率偏大，部分 PNG 尺寸超出 083 渲染上限，裁剪或缩放至同目录原版装备画布大小，防止穿模、贴图错位。

4. 保存 Character\.wz。

### 步骤 2：修改 Item\.wz（装备属性，改动最多）

打开 083 Item\.wz → equip → 对应分类前缀文件夹（130 单手剑 / 100 帽子），新建目标 ID\.img，逐条精简参数：

#### 必须删掉的字段（083 无逻辑）

`potential、addPotential、starForce、tode、setEffect、equipExp、upgradeMaxLv、cashOption、allStat%百分比属性`，出现即删。

#### 必须保留 \& 修正的 083 原生字段

|字段|修改规则|
|---|---|
|reqLevel|装备等级，083 最高可填 120，超 120 酌情下调|
|reqJob|职业码，083 五职业 \+ 海盗，新职业码（双弩 / 恶魔等）改成对应老职业编号|
|reqGender|0 男 1 女 2 全职业，沿用原码|
|incHP/incMP/incSTR 等属性|百分比属性改为固定数值（083 不支持 % 加成）|
|upgrade|可砸卷次数，083 上限 7，超 7 强制改成 5\~7|
|icon|小图标路径，高版本 icon 路径无效，替换成 083 同类型装备有效 icon 编号|
|cash|0 = 普通装备，1 = 点装，高版本点装标记按需改|

> 图标异常处理：高版本 icon 素材从原版本 Item\.wz/icon 导出 PNG，丢进 083icon 目录，或复用现有图标编号。
> 
> 

### 步骤 3：String\.wz 添加装备中文名 / 英文名

1. `String.wz/Eqp.img`内新建装备 ID 节点，填入名称、说明；

2. 缺失描述文案直接摘抄同品级 083 装备文本，高版本超长描述精简（083 聊天框、道具提示框字符上限低）。

### 步骤 4：Effect\.wz（可选，带特效装备）

高版本装备自带周身特效、进场特效，特效路径在 Item\.wz `effect`字段：

- 特效编号是高版本独有→要么删掉 effect 字段，要么把高版本特效 IMG 导入 083 Effect\.wz 并重编号。

### 步骤 5：客户端打包校验

1. 全部 WZ 保存后，替换 083 客户端原 WZ；

2. 开单机客户端用 GM 命令刷装备 ID，排查：白图、闪退、属性乱码、提示不存在。

## 三、服务端三层配套修改（缺改则刷不出、穿不上、爆不出）

### 1\. DB 装备数据表（items\.equipdata）

1. 插入新装备 ID 数据，**字段只保留 083 服务端原生字段**：等级、属性、职业限制、可升级次数、重量、价格；

2. 高版本独有数据库字段（潜能、星星、套装属性）全部舍弃，不写入数据库。

### 2\. 怪物爆率 Mob\.wz \+ 服务端 Drop 表

- Mob\.wz：对应怪物掉落新增装备 ID，设置掉落概率；

- 数据库 dropdata 表同步新增掉落配置，否则怪物不掉落。

### 3\. NPC 商店 / 锻造 / 任务奖励（可选）

- NPC 售卖：Script\.wz 对应 NPC 脚本添加商品 ID，服务端 npcshop 表录入售价；

- 任务奖励：Quest\.wz 奖励列表填入装备 ID，服务端任务数据库同步。

## 四、高频踩坑 \& 修正清单

1. **装备白贴图**：①Character\.wz 动作帧丢失；②icon 编号无效；③高版本 Canvas 格式不兼容，重新导出 PNG 替换。

2. **上线穿装备闪退**：Item\.wz 残留潜能 / 星星等高版本字段，全删后重存 WZ。

3. **GM 指令提示物品不存在**：①客户端 WZID 和服务端 DBID 不一致；②String\.wz 未注册 ID。

4. **属性数值异常超大**：% 百分比属性未转为固定值，083 运算逻辑不支持百分比。

## 五、最简快速移植方案（只拿外观、属性复用老装备）

1. Character\.wz 导入高版本 IMG→改成空闲 ID，只留动作贴图；

2. Item\.wz 直接复制 083 同款老装备的 IMG 属性，只改 icon 和 name，外观用新素材；

> 优点：不用改大量属性，极少报错，私服最常用。
