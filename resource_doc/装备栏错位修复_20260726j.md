# 装备栏错位（项链左上 / 武器悬停反了）— 2026-07-26j

## 对应现象
- 项链跑到**左上角**
- 项链右侧像又一个项链格，悬停却是**武器**
- **武器图标**上悬停没有信息
- 宠物装备可能看起来错位

## 根因
1. **左上角项链**：开启第二坠旗标后，经典绘制会多画 `GetSlotXY[50]`。我们曾把它写成 **`(0,0)`** → 图标画在窗口原点。  
2. **项链右=武器信息 / 武器图无信息**：v083 原生右侧栏 **HitTest 与 GetSlotXY 本来就不一致**（例：武器 HT=`(104,134)`，绘制 GS=`(137,134)`）。图标在 137，点中区在 104，看起来就像「空项链格是武器、真武器图点不到」。第二坠一乱更明显。  
3. **项链旁多一格**：旧补丁把 `BE27E0[51]` 改成主坠旁 `(48,132)`，已在 i 版改回；若仍看到残留，重开客户端加载 j 版 dll。

## 本次修复
| 项 | 处理 |
|----|------|
| `GetSlotXY[50]` | **`(336,165)`**（不再用 0,0） |
| `BE27E0[51]` | **`(336,165)`** 原生展开格 |
| HitTest | 对 BP 4/10–16 **对齐到 GetSlotXY**（武器/耳/戒悬停与图标一致） |
| ForceDrawLoop | 仍禁止 |

第二坠可视位置：装备栏**偏右展开区**约 `(336,165)`。若 UI 图未加宽，可能仍不好看，但不应再飞左上、不应再和武器抢悬停。

## 关于「扩图」
若 `UIWindow` 装备底图加宽了、坐标却仍用旧表，需要**整表重标定**（HitTest + GetSlotXY + BE27E0 + 宠物窗）。本次先修我们引入的错位与原生 HT/GS 不一致；完整扩图对齐可另开任务。

1. 确认 `ijl15_pendant2_VERSION.txt` 含 `20260726j`，dll 时间新  
2. **完全退出**客户端再开  
3. 项链不应在左上角；武器图标悬停应出信息  
4. 第二坠在窗口**右侧**；`@第二坠` 仍可用
