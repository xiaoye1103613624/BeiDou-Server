## 1. 设计总览

### 1.1 养成哲学

| 类别 | 策略 | 说明 |
|------|------|------|
| **核心成长** | 武器 + 套服 + 戒指 | 长期主线，链式进阶，属性继承 |
| **其他部位** | Boss 掉落 + 炼金合成 | 帽子/手套/鞋子/披风/腰带/耳环等不做长链 |
| **远征 Boss** | 独有装备 + 专属材料 | 不给武器链成品，避免跳级 |
| **全局货币** | 枫叶 `4001126` | 所有进阶系统的通用消耗 |

## 3. 三条核心成长线

> 详细数值以 `玩法/` 目录下三个 `.txt` 为准，此处为规划摘要。

### 3.1 武器线（9031003）

- **领取**：圣诞六翼天使武器系列，10 级，四维+20，不可交易
- **进阶**：共 19 阶，上一阶武器作材料，属性继承 + 增量
- **同类型链式**：单手剑→单手剑，短杖→短杖
- **全局倍率变量**：便于后期整体调控材料消耗

| 阶段 | 代表系列 | 目标等级 | 通用材料 |
|------|---------|---------|---------|
| 0 | 圣诞天使武器 | 10 | 免费领取 |
| 1–4 | 枫叶→4 周年枫叶 | 30–60 | 4011007, 4021009, 4000313, 枫叶 |
| 5–10 | 铂金→革命 | 70–120 | 同上 × 倍率 |
| 11–14 | 扎昆武器→皇家班雷昂 | 130–150 | + Boss 象征材料 |
| 15–19 | 巨匠→创世 | 160–200 | + 高阶远征材料 |

**Boss 材料接入（11 阶起）**

| 武器阶段 | 新增材料 |
|---------|---------|
| 扎昆武器（11） | 扎昆的象征 ×5 |
| 皇家班雷昂（13） | 黑龙之鳞 ×10 |
| 埃苏莱布斯（16） | 品克缤之羽 ×10 |
| 神秘之影（18） | 匠魂结晶 ×20 |
| 创世（19） | 匠魂结晶 ×50 + 四傻象征各 ×3 |

### 3.2 套服线（9031001）

- **购买起点**：`1052165` 降落伞工作人员套装（100W 金币）
- **进阶**：Lv0→Lv18，每次三选一属性路线
- **失败机制**：可配置成功率，失败只扣材料（与武器 100% 兑换区分）

| 路线 | 属性倾向 |
|------|---------|
| 伤害 | 双维+20, HP+100, 攻/魔+15 |
| 均衡 | 双维+15, HP+300, 攻/魔+10 |
| 血量 | 双维+10, HP+600, 攻/魔+8 |

**材料**：`4002000`–`4002003` 四色水晶 + 金币（按阶数递增）

### 3.3 戒指线（9031004）

- **起点**：`1112599` 十字旅团新手戒指
- **终点**：`1112613` 十字旅团降魔戒指
- **材料特点**：`4000000`–`4000039` 全等级段怪物掉落 + 枫叶

> 戒指是唯一「从早期怪就开始积累材料」的主线，不依赖 Boss。

## 10. 装备属性追加来源与分色方案

> **评估日期**：2026-08-01  
> **范围**：仅统计「能让**当前这件装备**面板属性增加」的养成来源；角色级 buff、套装效果、天赋、携带物等不计入。  
> **现状锚点**：客户端 ijl15 `fusionanvil/tooltip.cpp` 的 `EmitStatBreakdownLine` / `HyperBonusForStat`；服务端 `PotentialHyperService.computeBonus` + `PacketCreator.addItemInfo`。  
> **维护约定（强制）**：§10.3 色板为**唯一对照表**。后续凡新增/改动「装备强化或属性增加」玩法，必须先对照本表选色；新来源无对应色时**先在本表追加一行**再实现 tip / 封包 / 脚本展示，禁止私自另开色系。

### 10.1 展示现状（已实现）

装备 tip 属性行已拆成「总值 + 括号分解」，形态近似：

```text
力量 +120 (80+20 +15 +5+2%)
           │  │   │   └── 潜能%（括号右侧）
           │  │   └────── Hyper★ / 潜能 flat（括号右侧，单色）
           │  └────────── 本体相对底板增量（砸卷等写入 body）
           └──────────── 底板（WZ 模板）
```

| 片段 | 当前颜色 | 技术限制 |
|------|---------|---------|
| 标签 + 总值 + `(底板[+本体增量]` | tip 标签字（白/默认） | `AddInfoEx` 左字体槽 |
| Hyper★ 追加 | **金黄**（font tip #2） | 有 Hyper 时右侧整段用黄 |
| 仅潜能追加（无 Hyper） | **浅绿** `#6ED86E` | 临时 remap purple 槽 |
| Hyper + 潜能同时存在 | 右侧**同色金黄**混写 | **双色上限**：右半只能一种颜色 |
| 主潜能/附加/灵魂/星岩 **区块标题** | 黄 / 青 / 品红 / 银灰 | 已按 section bar 分色 |
| 潜能词条文本 | 品阶色（灰→蓝→紫→金→绿） | `kPotGradeArgb` |

**关键结论**：括号内「多来源各自一色」不能靠 `AddInfoEx` 一条线完成，需自绘多段 `DrawTextA`（或拆多行）。分色方案按「可独立计算的来源」设计，分两期落地。

### 10.4 方案评估与分期

#### 难点 1：「本体增量」是混桶

客户端今日算法：

```text
本体增量 = 封包板值 − Hyper − 潜能flat − WZ底板
```

其中「封包板值」来自服务端 `equip.getStr()` 等，已含：正向卷、混沌、鉴定、进阶继承、勋章覆写、Maker… **无法在纯客户端再拆成「纯砸卷 vs 鉴定 vs 进阶」**，除非服务端下发分项或约定 owner/扩展字段记账。

| 策略 | 做法 | 利弊 |
|------|------|------|
| **A. 混桶橙（推荐一期）** | 括号只显示一截「强化 +N」橙色 | 实现快；玩家仍能区分星力/潜能；进阶/鉴定细节靠 owner 与 NPC |
| **B. 服务端分项封包（二期）** | `addItemInfo` 尾部带 scroll/identify/chain 分项 short | 真·分来源；要改封包与 ijl15 解码 |
| **C. owner 词条反算鉴定** | 解析「N阶X」估鉴定值 | 仅鉴定可拆；进阶仍混在砸卷里；GBK/格式脆弱 |

**一期采用 A**；鉴定继续用 owner「N阶X」文本行作补充说明。

#### 10.4.5 混沌卷轴能否单独分色？

**结论：现状不能；加记账后可以。**

| 点 | 说明 |
|----|------|
| 现状 | `scrollOptionEquipWithChaos` 与正向卷一样直接改 `equip.str/watk…`，`Equip` **无**混沌累计字段；砸完后与普通卷在 body 上不可逆混同 |
| tip | 负向混沌时客户端刻意不伪造砸卷段（`scrollDelta < 0` → 整段并进板值），更无法单独染色 |
| 要单独绿 | 砸混沌时按属性累加 `chaosStr/Dex/…`（可负），存 DB + 进封包；tip：`橙 = 本体增量 − 混沌累计`，`绿 = 混沌累计`（负值显示 `-N`） |
| 旧装 | 记账上线前已砸过的装备无法回算，只能整段留在橙桶，或 GM/白板后重砸 |
| 色板 | 深绿 `#FF2DB84D` **已预留**；未接线前 tip **不显示**该色，避免空段 |

不建议用「是否用过混沌」布尔标记凑合：一次混沌后的数值与多次正向卷无法从结果反推。

#### 难点 2：`AddInfoEx` 双色上限

有 Hyper 时潜能 flat 已与星力同色混写。要「黄 / 紫 / 青…」并存，必须：

1. 自绘属性行（多段 `DrawTextA` + 各色 font），或  
2. 拆成多行（`力量 +150` + 下一行小号 `基础80 强化35 星力20 …`）。

推荐 **1（同行多色）**，视觉密度与现网括号一致；图例行可折叠。

#### 难点 3：潜能 / 灵魂 / 星岩 数字拆分

`computeBonus` 与 tip 的 `PotentialFlatForStat` 今日把主潜+附加+灵魂 option+星岩 **加总**。分色需要 tip 侧按字段分别 `SumOptKey`：

- 主潜：`potential1/2/3`
- 附加：`bonusPotential1/2/3`
- 灵魂：orb 表或 `soulOption`
- 星岩：`socket1/2/3`

服务端战斗无需改；仅 tip 展示拆开即可。

#### 难点 4：双星力系统

Hyper `enhance`（virtual）与旧版 `EquipEnhanceManager`（body）并存会造成「星力色」语义混乱。玩法上 **以 Hyper★ 为唯一星力展示色**；旧 DB 星力迁完前不单独开色。

#### 分期落地

| 期 | 内容 | 依赖 |
|----|------|------|
| **P0（文档+色板冻结）** | 本表；色板写入 ijl15 常量区备查 | 无 |
| **P1（客户端）** | tip 自绘：底板白 / 本体橙 / Hyper 黄 / 潜能紫；附加·灵魂·星岩有值则续色 | ijl15 `EmitStatBreakdownLine` 改造 |
| **P2（展示拆分）** | 潜能合计拆成 主紫 / 附青 / 魂粉 / 岩灰 | tip 按字段 sum |
| **P3（洗炼）** | `ReforgeService` 接入 `computeBonus` + 珊瑚红 | Java + tip |
| **P4（可选）** | 本体混桶再拆砸卷/鉴定/进阶；**混沌深绿**需 `chaos*` 累计字段 | 扩展封包或成长记账表 |
| **维护** | 新强化来源 → 先改 §10.3 色板再写代码 | 文档先行 |

### 10.5 与三条核心成长线的关系

| 成长线 | 属性如何进装备 | tip 落在哪一色 |
|--------|---------------|----------------|
| 武器 19 阶 | 换装时写入 body | **橙（本体成长）**；再叠星力黄、潜能紫等 |
| 血衣 18 阶 | 同上 | 同上 |
| 成长戒指 14 阶 | 同上 | 同上 |
| 部位 Boss/炼金成品 | 掉落或合成 body | 同上起步，再走卷/星/潜 |
