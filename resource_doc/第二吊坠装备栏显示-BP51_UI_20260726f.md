## 3. 为何以前不显示（技术）

| 环节 | 旧实现 (e) | 实际 |
|------|------------|------|
| 绘制循环 | 以为写 `BED650+0x5E8` 即可 | 循环在 **`0x007FDE7C`**，`lea`/`mov` 的是 **drawer this+0x5E8** |
| GetSlotXY | hook `0x007FEFEA` index==50 | hook 在，但 **flag 未开 → 根本不调 index 50** |
| 坐标 | (71,68) | 眼饰列上方，易被当成眼饰 |
| ForceDrawLoop | 未动（正确） | 仍禁止 |
