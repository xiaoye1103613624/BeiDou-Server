# 挑战副本分层规划

> 远征（083 原版）与挑战副本分离。远征走 `ExpeditionType` + 原版 NPC；挑战副本走 `9031000` 枢纽，掉落由 `drop_data` 控制。

## 一、三层结构

| 层级 | 定位 | 主要产出 |
|------|------|----------|
| **普通挑战副本** | Lv70+ 材料本 | 勇者/圣者之石、C/B 级宝石、Boss 特产材料 |
| **进阶挑战副本** | Lv120+ 饰品本 | 同上 + 鲁塔比斯符文/封印箱、希纳斯/扎昆饰品 |
| **团队副本** | Lv140+ 后期本 | 同上 + A/S 级宝石、四凶/暴君装备材料 |
| **083 远征** | 原版机制不变 | 巨型蝙蝠怪额外强化（见下） |
