## 2. 为何上次会卡登录

DllMain 同时开三条：

| ID | 内容 | 地址 | 风险 |
|----|------|------|------|
| **A** | ForceDrawLoop：`setnz`→`mov al,1` 恒扫到 index 50 | `0x007FEFB9` | **最高危**：GetSlotXY(50) 无界读 `BE2710`；登录期若碰到绘制即炸 |
| **B** | GetSlotXY detour | `0x007FEFEA` | 与 A 配对才不 OOB；DllMain 全局挂钩 |
| **C** | GetBodyPartFromPoint | `0x007FEC32` | 另有 `0x4F1A52` / `0x4F4DBE` 穿戴拖放 xref |

现象：AuthSuccess 后停住 → 无选角/进频道 → ~45s ALL_IDLE。

---

## 3. 本次「能显示」方案（窄 / 可关）

### 原则

1. **禁止** 再 patch ForceDrawLoop（`0x007FEFB9` 永不动）
2. **禁止** DllMain 挂 UI；仅 **首帧 CField 之后** `EnsurePendant2AfterFieldEnter`
3. GetSlotXY：**仅** `index==50` 返回外挂坐标 `(71,68)`；其它 index 走原函数
4. HitTest：原函数未命中时，再测 `(71,68)` 32×32 → 返回 bodypart **51**
5. 绘制上界：写 **原生** `*(CUIEquip* + 0x5E8) = 1`（绘制循环 `setnz` 本就读此 flag），进图后 tick 维持；**不**改机器码
6. Feature flag：`pendant2_ui`（默认 **false**）

### 代码 / 配置

| 位置 | 内容 |
|------|------|
| `BeiDou-ijl15/ezorsia/pendant2/pendant2.cpp` | 安全 UI 实现 |
| `LazyCompatInit.cpp` | 进图后 `EnsurePendant2AfterFieldEnter` + tick 泵 flag |
| `config.ini` `[optional] pendant2_ui` | **false** 默认；**true** 才显示/可点 |

## 4. 如何开显示 / 如何关

### 开（显示并点击 −51）

1. 确认当前 `pendant2_ui=false` 时：**LoginFlow 正常**（见下节）
2. 关客户端；`config.ini` 改 `pendant2_ui=true`（勿带 UTF-8 BOM）
3. 开 `BeiDou-Client_1` → 再过一遍 LoginFlow
4. 进图开装备栏：第二坠约在 **(71,68)**（主坠上方附近）；应能看见图标并点击/拖放
5. 仍可用 `@第二坠` / `@第二坠 卸下` 作旁路

### 关（回到仅属性、栏不显示）

- `pendant2_ui=false`（或删键，默认 false）→ 重开客户端  
- 或从 `_ijl15_backup` 还原 dll（一般不必，关 flag 即可）

### 紧急回滚（卡登录）

1. 关所有 `BeiDou.exe`
2. `_ijl15_backup\ijl15.dll.*.bak` → 覆盖 `ijl15.dll`（或 `pendant2_ui=false` 后重开）
3. 确认 `ijl15_pendant2_VERSION` / 肩饰仍 ON
