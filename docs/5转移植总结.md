## 未解决:v83 客户端渲染限制

- **3131003**:✅ 端到端可用(转职→超技→伤害→怪死)
- **3131056 / 3131012 / 3131007**:释放时 GR2D **D3D8 vtable[1] 空指针**(EIP=0,秒崩或一帧后卡)
- **根因(已确诊)**:
  - MR 与 BD 客户端**唯一文件差异 = `d3d8.dll`**(D3D8→D3D9 包装器,MD5 对比确认;exe/GR2D/ResMan/所有 DLL/技能数据字节级相同)
  - MR 靠该包装器补全 D3D8 渲染 vtable + **MR 插件的隐性配合机制**(MR 插件源码无 D3D8 代码,其它 hook 让 D3D8 初始化通过)
  - BD 无法加载任何自定义 d3d8(MR 版、dgVoodoo 版均启动乱码;非 GameGuard 问题,stub 掉 nmcogame.dll 无效)
- **结论**:3 个技能是 v83 客户端渲染限制,服务端 5转 本身完整正确
