# 扩展功能：新增指令与道具说明

> **维护约定**：凡扩展功能**新增 / 修改**了聊天指令（`@` / `!`）或专用道具，必须同步更新本文档。  
> 指令是否生效以库表 `command_info`（Flyway 迁移）为准；`CommandsExecutor` 内硬编码注册已注释，仅 DB 启用才可用。  
> 玩家指令前缀 `@`；GM 可用 `@` 或 `!`（等级以 `command_info.level` 为准）。

| 前缀 | 适用 |
|------|------|
| `@` | 玩家 + GM |
| `!` | 仅 GM（玩家发 `!` 不会当指令） |

文档结构约定（每个功能一节）：

1. **功能说明**
2. **指令**（无则写「无」）
3. **道具**（无则写「无」）
4. **操作流程与效果**

## 1. 美容院

### 功能说明

自定义美容院：保存多套发型 / 脸型 / 肤色方案，在 UI 内切换应用。数据表 `xy_beautystorage` / `xy_beautyunlock`。

### 指令

| 语法 | 等级 | 说明 |
|------|------|------|
| `@美容美发` | 0 | 打开美容院界面 |
| `@beauty` | 0 | 同上 |

> 备注：源码草稿里还有别名「美容院」，Flyway 未插入，当前库以 `美容美发` / `beauty` 为准。

### 道具

| itemId | 名称 | 说明 |
|--------|------|------|
| **5920000** | 美容院解锁券 | 现金道具；每张解锁 +1 保存槽，最多 6 槽 |

### 操作流程与效果

1. 聊天输入 `@美容美发`（或侧栏 / NPC 便民入口）→ 服务端发美容院 OPEN + DATA 封包 → 客户端打开窗口。
2. 在窗口内保存 / 应用已解锁槽位的发型、脸型、肤色。
3. 双击现金栏 **5920000**（或美容院内用券）→ 消耗 1 张 → 解锁槽 +1（上限 6）→ 刷新栏位数据。
4. **效果**：外观方案可持久保存并一键切换；未解锁槽在 UI 中为灰色锁定。

## 2. 每日签到

### 功能说明

28 天循环签到窗口。等级门槛见 `DailyCheckinRewards.MIN_LEVEL`（当前 **10**）。领奖走签到封包 Claim，不是本指令直接发奖。

### 指令

| 语法 | 等级 | 说明 |
|------|------|------|
| `@签到` | 0 | 打开每日签到窗口 |
| `@daily` | 0 | 同上 |

### 道具

无专用道具。奖励在 `DailyCheckinRewards.DAYS` 配置（当前占位：图标 2000000、每天 1 金币、无物品）——运营改奖励时改该类并同步本文档。

### 操作流程与效果

1. 角色 ≥ 10 级后输入 `@签到`，或点侧工具栏「每日签到」。
2. 服务端 `refreshCheckin()` 后下发 `dailyCheckinSnapshot`；冷却中会提示剩余小时/分钟。
3. 玩家在窗口内点击可领天数 → `DailyCheckinHandler` → `DailyCheckinRewards.grantDay`。
4. **效果**：按天发放配置的金币 / 物品 / 背包扩容；冷却约 24 小时一轮。

## 3. 七彩棱镜（装备 / 外观染色）

### 功能说明

现金道具打开染色窗，可对装备本体、装备特效、技能特效、发型、瞳色、肤色做 HSL 染色。确认时消耗棱镜。

### 指令

无。

### 道具

| itemId | 名称 | 说明 |
|--------|------|------|
| **5782000** | 七彩棱镜 | 现金栏双击打开 `ColorPrism` UI；一次道具覆盖窗口全部 Tab |

### 操作流程与效果

1. 现金栏双击 **5782000** → 客户端打开七彩棱镜窗口（`ColorPrism.img`）。
2. 选择目标（装备 / 特效 / 发型 / 脸 / 肤）→ 调色相 / 饱和 / 亮度 → 确认。
3. 服务端 `WeaponTintHandler` / 染色相关 Handler 校验道具归属与目标，写入染色字段并消耗棱镜。
4. **效果**：目标外观按选定 HSL 显示；还原操作可清染色（同样校验棱镜等规则，见 Handler）。

## 6. 收纳背包

### 功能说明

矿石 / 卷轴 / 椅子 / 坐骑等分类收纳；支持自动收纳开关。无专用打开道具。

### 指令

无（参考素材里的 `@orebag` 等未在本服实现）。

### 道具

无。

### 操作流程与效果

1. 按 **F9**，或背包 BAG 按钮，或侧栏「收纳背包」→ `BagWindowHandler`。
2. 收纳窗打开时，在主背包**右键**物品可直接存入对应分类（装备→坐骑 / 消耗→卷轴 / 设置→椅子 / 其他→矿石）。
3. 在窗口内存取物品、开关自动收纳（`REQ_SET_AUTO`）。
4. **效果**：指定类型物品进入收纳空间，主背包更清爽；数据在 `xy_` 收纳相关表（见 `V1.11.11__storage_bag.sql`）。

> 注：原「背包锁格」（右键锁格、整理跳过锁格）已移除；整理/聚合会压紧为空隙连续排列。

## 7. 远征死亡次数

### 功能说明

远征副本共享死亡次数 UI；次数由 `game_config` 按远征类型配置（0=关闭）。默认示例：扎昆 10、进阶扎昆 5，其余多为 0。

### 指令

| 语法 | 等级 | 说明 |
|------|------|------|
| `!deathcount` | 3 | 查看当前远征死亡次数 |
| `!deathcount <n>` | 3 | 设置为 n；**-1** 表示关闭 |

### 道具

无。

### 操作流程与效果

1. GM 须处于远征 EventInstance 中。
2. `!deathcount` 报告类型与当前 count；带参数则改写并广播客户端 DeathCount UI。
3. **效果**：队员死亡扣共享次数；归零时按远征逻辑处理（退出/失败等，见 Expedition 实现）。

## 8. 天气 / 昼夜 / 路灯

### 功能说明

世界级时间与天空强制覆盖（非单地图）；洞穴等无天空地图忽略。路灯指令仅**预览**坐标，不写库。

### 指令

| 语法 | 等级 | 说明 |
|------|------|------|
| `!weather` | 2 | 报告当前时间与天空 |
| `!weather day\|dusk\|night\|dawn\|midnight` | 2 | 冻结时间段 |
| `!weather clear\|rain\|snow\|...` | 2 | 强制天空（见 WeatherProfile） |
| `!weather night rain` | 2 | 时间与天气可同写、顺序任意 |
| `!weather 21:30` | 2 | 冻结到指定时刻 |
| `!weather auto` | 2 | 解除覆盖，交还世界时钟 |
| `!night` | 3 | 快捷：世界冻结黑夜（恢复用 `!weather auto`） |
| `!lamp` | 3 | 列出可用路灯 ID |
| `!lamp <id>` | 3 | 在脚下预览路灯并打印 `{ mapId, x, y, id }` |
| `!lamp clear` | 3 | 清除本图预览路灯 |

### 道具

无。

### 操作流程与效果

1. GM 用 `!weather` 查看或强制 → `WeatherService` 设 override → 全频道广播天空/时间封包。
2. 覆盖有持有时间（`OVERRIDE_HOLD_MS`），防止 GM 下线后世界一直卡住；`auto` 立即清除。
3. `!lamp` 用于摆灯选点：预览仅客户端临时显示，复制打印行写入永久表后需另内部署。
4. **效果**：全服可见昼夜/雨雪等氛围变化；路灯预览帮助配置夜间照明点。
5. **管理端 Web**：`游戏管理 → 天气切换`（`/game/weather`）。页面上中文展示；**时段与天空两条轴组内互斥、组间可组合**（同 `!weather night rain`）。「恢复自动」= `!weather auto`。接口走 `WeatherService`/`WeatherPackets`，**不改** `WeatherCommand` / `NightCommand` 原有逻辑。

### 指令组合 / 互斥（Web 与聊天一致）

| 关系 | 说明 | 示例 |
|------|------|------|
| 组内互斥 | 时段词只能选一个；天空词只能选一个 | `day` 与 `night` 不能同时生效 |
| 组间组合 | 时段 + 天空可同写、顺序任意 | `!weather night rain` / `!weather rain night` |
| 交还全部 | `auto` 同时清时段冻结与天空强制 | `!weather auto` |
| 仅清一侧 | Web 提供「仅解除时段 / 仅解除天空」；聊天指令无单独语法，需用 `auto` 或再设另一侧 | Web：时段=仅解除时段冻结 |
