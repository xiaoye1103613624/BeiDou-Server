# 扩展改动：活动管理系统

> 范围：官方 GM 活动 + 打瓶盖 / 羊狼牧场 / 小游戏挑战 + 跳跳类；启停、排期、报名传送、奖励结算（排名/团队/参与）、名字公示。  
> 迁移：`V1.11.27__activity_management.sql`、`V1.11.28__activity_rewards.sql`

---

## 1. 目标与原则

1. **玩法只产出成绩**（outcome / rank / team / score），不在各活动脚本里散落 `gainItem`。
2. **结算器统一发资格**：成绩 → 匹配奖励档 → `activity_reward_claim`。
3. **领取通道统一**：`AUTO_BAG` 即时背包 / `CLAIM_NPC` 获奖处 / 背包满保留 PENDING。
4. **与 GM 指令共存**：管理端与 `@joinevent` / `@leaveevent` 共用同一套场次；无管理场次时仍走经典即时进场。

## 3. 生命周期与排期

```
IDLE → NOTIFYING → REGISTERING → PREWARP → RUNNING → STOPPED
```

| 能力 | 行为 |
|------|------|
| 单次 / 每日 / 每周 | `activity_schedule`，指定 world+channel |
| T-30 起每分钟公告 | `notify_minutes` / `notify_interval_sec`（默认 30 / 60） |
| T-5 自动传送 | 报名玩家传送；已在相关图内重置到 lobby 入口 |
| 开赛 | 支持图调 `MapleMap.startEvent`；大厅≠赛场则先送入赛场 |
| 同频道互斥 | 一频道同时仅一场活跃活动 |
| 停止/清场 | **先结算奖励**，再关报名 / 传出 `109050001` |

玩家：`@joinevent` 报名（管理场次不立即进图），`@leaveevent` 取消。

## 4. 奖励模型（核心扩展）

### 4.1 表

- `activity_reward_tier`：档位（条件 JSON + 奖池 + 领取方式 + 名字公示）
- `activity_participant_result`：场次成绩
- `activity_reward_claim`：领取单（PENDING / CLAIMED / EXPIRED，默认 24h）

### 4.2 成绩字段

| 字段 | 用途 |
|------|------|
| outcome | WIN / LOSE / DRAW / COMPLETE / ELIMINATED / PARTICIPATED |
| teamId | 红蓝队 |
| rankNo | 个人名次 |
| score / finishTimeMs / tags | 积分、用时、mvp 等 |

### 4.3 档位条件 `match_json` 示例

```json
{"outcomes":["WIN","LOSE","PARTICIPATED"]}
{"rankFrom":1,"rankTo":1}
{"rankFrom":2,"rankTo":3}
{"scoreMin":100}
{"finishTimeMaxMs":180000}
{"tags":["mvp"]}
```

- `priority` 越小越先匹配；同 `exclusive_group` 只发一档（如 `rank`、`result`）。
- 一活动可挂多档并行：参与奖 + 胜方/名次奖。

### 4.4 领取方式 `grant_mode`

| 模式 | 行为 |
|------|------|
| AUTO_BAG | 结算时进背包；失败则 PENDING |
| AUTO_MAIL | 当前同 AUTO_BAG（邮件通道预留） |
| CLAIM_NPC | 仅写领取单，获奖处 NPC `9000002` 领取 |

### 4.5 名字公示

档位 `announce_name=1`：结算时全服聊天框 + 标题公告。  
模板：`{0}` 角色名，`{1}` 活动名，`{2}` 档位名。

### 4.6 自动成绩采集（停止时）

1. 报名角色 → 至少 `PARTICIPATED`
2. 相关地图在线角色并入
3. 在 `109050000` 获奖处 → WIN / COMPLETE，并按顺序赋 `rankNo`
4. 团队：椰子比分定胜负；否则以获奖处队伍为胜

也可后台「立即结算」或 `POST /activity/v1/settle` 传入手工 `results`。

### 4.7 默认种子档位摘要

- 团队（椰子/雪球/瓶盖）：参与金 + 胜方证书(4031019)+公示 + 败方安慰金  
- OX/上楼/体能：参与 + 通关 + RANK1 证书公示 + RANK2–3  
- 寻宝：参与 + 寻得(COMPLETE/WIN) 证书公示  
- 休闲跳跳/羊狼/小游戏：参与 + 通关金  

后台「奖励配置」可改档位，无需改代码。

## 5. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/activity/v1/list` | 目录+实时状态 |
| POST | `/activity/v1/setEnabled` | 启用 |
| POST | `/activity/v1/openRegistration` | 开放报名（可带 plannedStartAt） |
| POST | `/activity/v1/closeRegistration` | 关闭报名 |
| POST | `/activity/v1/start` | 开始 |
| POST | `/activity/v1/stop` | 停止（含结算） |
| POST | `/activity/v1/stopAndClear` | 停止清场（含结算） |
| POST | `/activity/v1/warpAllOut` | 全部传出 |
| GET/POST | `/activity/v1/schedules` / `saveSchedule` / `deleteSchedule` | 排期 |
| GET/POST | `/activity/v1/rewardTiers` / `saveRewardTier` / `deleteRewardTier` | 奖励档 |
| POST | `/activity/v1/settle` | 手动结算 |
| GET | `/activity/v1/sessionClaims` | 场次领取单 |

前端：日常系统 → **活动管理**。
